# R. Akshai Kumar — Bioinformatics Portfolio

This package contains the portfolio website and your original CV PDF.

## Files
- `index.html` — portfolio website
- `assets/Akshai_Kumar_CV.pdf` — original CV

## GitHub Pages
Create a repository named `R-Akshai-kumar02.github.io` (or another repository and enable Pages), upload these files, then enable **Settings → Pages → Deploy from branch → main**.

The website's **View / Download CV** button already points to the included PDF.
